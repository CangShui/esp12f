## 1. 板子是什么

一块电脑**远程开关机卡**：板载 ESP8285N08 模块 + 电源键/复位键驱动电路，
通过模拟"按电源键"和"按复位键"来控制主板。

| 项 | 值 |
|---|---|
| 模块 | ESP8285N08（ESP8266 内核 + 内置 1MB Flash） |
| MAC | `ec:94:cb:84:92:06` |
| ChipID | `0x00849206` |
| 晶振 | 26MHz（串口默认波特率因此是 74880） |
| 原厂固件 | `esp8266_V1.1`，SDK `NONOSDK22x_190703` |

## 2. 接线图解

### 2.1 刷写接线（CH341A ↔ ESP8285）

```
   CH341A 编程器                       ESP8285 模块
   ┌──────────────┐                    ┌──────────────────────┐
   │ 1 TXD ●──────┼────交叉───────────→│ A RXD                │
   │ 2 RXD ●──────┼────交叉───────────→│ B TXD                │
   │ 3 GND ●──────┼────共地───────────→│ C GND                │
   │ 4 3V3 ●──────┼────供电───────────→│ D 3V3                │
   │              │                    │                      │
   │ DTR/RTS 不接 │                    │ E GPIO0 ──→ GND      │
   └──────────────┘                    │   （仅刷写时短接）    │
                                       └──────────────────────┘
```

| 编程器 | 模块 | 说明 |
|---|---|---|
| **TXD** | **RXD** | 必须交叉 |
| **RXD** | **TXD** | 必须交叉 |
| **GND** | **GND** | 必须共地 |
| **3V3** | **3V3** | 由编程器供电（也可模块独立供电） |
| DTR / RTS | 不接 | 本模块不支持自动复位，必须手动进下载模式 |
| — | **GPIO0 → GND** | **仅刷写时需要**，刷完必须断开 |

> ⚠️ **CH341A 跳线必须切到 3.3V**。出厂默认 5V，直接接 ESP8285 会打坏芯片。
> 实测该 CH341A 的 TXD 空闲电平约 4.6V，切到 3.3V 后约 3.3V。

### 2.2 正常运行接线

刷写完成后，**GPIO0 必须悬空**，模块由原板电路供电，无需 CH341A。
串口线可以留着（用于看日志），也可以拔掉。

## 3. 进入下载模式（关键步骤）

ESP8266 **只在复位瞬间采样 GPIO0**，所以顺序不能错：

```
① GPIO0 接到 GND 并保持
        ↓
② 给模块断电
        ↓
③ 再上电（此时 GPIO0 仍是低）
        ↓
④ 芯片进入 UART 下载模式，保持 GPIO0 接地
        ↓
⑤ 运行刷写脚本
        ↓
⑥ 刷完：断开 GPIO0 与 GND，再断电上电一次
```

**三个常见误区：**

| 误区 | 事实 |
|---|---|
| "按住板上按键上电就能进下载模式" | ❌ 板上按键接的是 **GPIO4**（配网按钮），不是 GPIO0 |
| "下载模式下串口应该有输出" | ❌ 下载模式下**一个字节都不打印**，静默是正常的 |
| "接好线就能直接连" | ❌ 必须先完成上面的断电上电时序；串口一关就退出下载模式，每次连接都要重来 |

## 4. GPIO 定义表

| GPIO | 方向 | 作用 | 反汇编证据 |
|---|---|---|---|
| **2** | 输出 | 状态指示灯（低电平点亮） | `digitalWrite(2,1)` @ `0x40203EDA` |
| **12** | 输出 | 电源键：高 500ms = 开/关机切换；高 8000ms = 强制关机 | `0x40203BB2 / 0x40203BBB / 0x40203BC5`；`0x40203BF1 / 0x40203BFA / 0x40203C04` |
| **5** | 输出 | 复位键：高电平脉冲 200ms | `0x40203CAE → 0x40203CCE` |
| **14** | 输入 | 电源状态：**高 = 已开机** | `digitalRead(14)` @ `0x40203AF6`（真机确认） |
| **4** | 输入(内部上拉) | **配网按钮**：低 = 按下 | function A `0x402039EC` 首条即 `digitalRead(4)`；字面量池含 `"\r\nWait for Webconfig"`；真机实测按下时 1→0 |

### 状态极性实测记录

| 时刻 | GPIO14 | GPIO4 | 判定 |
|---|---|---|---|
| 电脑未接入 | 0 | 1 | 电源已关闭 |
| 电脑接入并开机 | **1** | 1 | **电源已开启** |
| 按下板上按钮瞬间 | 1 | **0** | 配网按钮按下 |
| 松开按钮 | 1 | **1** | 恢复 |

因此 `config.h` 里 `STATE_ACTIVE_HIGH = 1`（GPIO14 高电平 = 已开机）是正确的。
若你的板子极性相反，把该值改成 `0` 重新编译即可。

## 5. 上电时序（复刻原厂 `setup()`）

原厂 `setup()` @ `0x40203EC8` 的顺序：

```
digitalWrite(2, 1)        // 指示灯灭
pinMode(12, OUTPUT)       // 电源键
pinMode(14, INPUT)        // 电源状态
pinMode(5,  OUTPUT)       // 复位键
pinMode(4,  INPUT_PULLUP) // 配网按钮
digitalWrite(5, 1)        // 复位键拉高
delay(500)
while (digitalRead(4)) {} // ← 原厂在这里无限等待按钮按下
digitalWrite(5, 0)        // 复位键拉低
```

新固件**完整复刻**这段时序，只把「无限等待」改成**最多等 2 秒**
（`T_BOOT_SENSE`），避免硬件没接好时卡死在启动阶段。

而且这段等待被赋予了新用途：**等待期间按钮按下 → 进入配网模式**
（原厂行为），超时未按 → 正常联网。

用 `config.h` 里的 `BOOT_USE_RST_HOLD` 可以关掉整个 GPIO5 时序：

```c
#define BOOT_USE_RST_HOLD   1   // 1=复刻原厂时序（默认）；0=上电不碰 GPIO5
```

如果发现**每次上电都会动到主板复位/继电器**，把它改成 `0`。

## 6. 供电注意事项

- 模块由原板电路供电时，**CH341A 的 3V3 不要再接**，否则两路电源打架
- 若要独立供电，CH341A 的 3V3 输出电流有限（约 100mA），WiFi 发射瞬间可能掉电，
  建议用独立 3.3V 电源并保证 ≥ 300mA
- 天线区域**不要覆盖金属**，否则信号差到连不上
